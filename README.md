# Campus---Calculadora-Nutricional-R-pida
Una startup de tecnología para la salud te ha contratado para desarrollar un prototipo rápido de una de las funciones clave de su nueva aplicación de nutrición. Necesitarán un programa simple que pueda calcular el total de calorías de una receta basándose en sus tres macronutrientes principales: proteínas, carbohidratos y grasas.
